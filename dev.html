ボートライズ

競艇選手になって、自分の艇を操縦するレースゲーム。右手のレバーと左手のハンドルで、3周6ターンを走り抜けます。

FEATURES機能紹介

  • ピット離れから待機行動までレース前のピット離れや待機行動から、競艇選手の動きをそのまま体験できます。
  • 12秒針のフライングスタート大時計の12秒針に合わせてスタートを切る、競艇ならではのフライングスタートを再現しています。
  • レバーとハンドルで1マークへ右手のレバーでスピードを、左手のハンドルで向きを操り、1マークのターンを決めて3周6ターンを走り抜けます。

PROCESS制作過程

企画設計開発テストリリース
  1. 企画競艇選手になって自分の艇を操縦する、本格的なボートレースゲームとして企画しました。
  2. 開発ピット離れ・待機行動・フライングスタート・ターンまで、実際のレースの流れをゲームで再現しています。

シケタイマッチング

同じ学科の過去問を、みんなで共有。大学・学部・学科ごとに、定期試験の過去問を見せ合える試験対策アプリです。

FEATURES機能紹介

  • 学科ごとに過去問を共有登録した大学・学部・学科の中だけで、科目・年度ごとに過去問を閲覧・投稿できます。
  • 画像10枚またはPDFで投稿問題用紙を写真（最大10枚）か PDF で投稿。答案や個人情報が写っていないか、投稿前に確認する仕組みです。
  • ログイン不要・安心の通報機能メールやパスワードの登録は不要で、所属を選ぶと ID が自動で発行されます。通報が3件集まった投稿は自動で非表示になります。

PROCESS制作過程

企画設計開発テストリリース
  1. 2026.10企画・開発スタート。閲覧・投稿・通報・所属登録の画面をひと通り作りました。
  2. 2026.10ログインをなくし、所属登録の時に ID を自動で発行する方式に変更しました。
  3. 2026.10サーバー（Firebase）と連携し、同じ学科の人と過去問を共有できるようになりました。
  4. 2026.10所属の変更（有料）や、投稿の削除ルールなど公開に向けた仕組みを追加しました。

受験まとめ

受験と就職活動の気になる話題を、まとめ記事で読みやすく。中学受験・高校受験・大学受験・就職活動に関する掲示板の投稿を、ジャンルやテーマから探せるアプリです。あちこちにある受験関連のまとめサイトを、このアプリひとつで一気見できます。

FEATURES機能紹介

  • まとめサイトを一気見受験関連のまとめサイトの記事を、サイトごとに見に行かなくても、ひとつのアプリでまとめて読めます。
  • 受験から就活までまとめて中学受験・高校受験・大学受験・就職活動の話題を、ひとつのアプリでチェックできます。
  • まとめ記事で読みやすく掲示板の投稿を、読みやすいまとめ記事の形でお届けします。
  • ジャンル・テーマから探せる気になるジャンルやテーマから、読みたい話題をすぐに見つけられます。

PROCESS制作過程

企画設計開発テストリリース
  1. 開発中学受験から就職活動まで、掲示板の投稿をジャンル・テーマ別にまとめる仕組みを作りました。
  2. テストTestFlight でテストを行い、公開に向けて仕上げています。
